# 寄語章節

> 2026-10-07 更新：目前實作已改為「每四人一組」的橫向循環寄語；以下若仍有單一長列表或不使用 JavaScript 輪播的舊描述，以本節為準。

## 目前的四人分組輪播

- `.messages-track` 內每位參與者對應一張 `.message-card`，JavaScript 會依 DOM 順序每四張建立一個 `.message-group`。
- 一個視覺畫面最多顯示四人，使用兩欄、兩列且較緊密的交錯構圖，不做死板齊頭排列。
- 左右箭頭及觸控橫滑可切換前後一組；首尾相接循環，但不自動播放，以免打斷閱讀。
- 桌機箭頭固定在輪播左右預留的安全區，不覆蓋卡片；窄螢幕則固定排列在卡片下方。
- 所有分組共用同一個網格舞台，舞台高度以內容最高的一組為準，因此切換至不足四人的尾組時，箭頭與後續內容都不會上下跳動。
- 人數可自由增加，組數由實際卡片數量自動推算；尾組不足四人時不補空卡，會依實際數量平衡位置。
- 若只有一組，左右箭頭隱藏；`prefers-reduced-motion` 下直接完成換組。
- 修改時需檢查末組與首組的雙向循環、快速連點防護、非目前組的 `aria-hidden`／`inert`，以及手機橫滑不攔截垂直捲動。

## 位置與用途

- `#messages-page` 位於繪春信與謝花人之間，是第 05 章；謝花人順延為第 06 章。
- 選單 key 為 `messages`，顯示名稱暫用「寄語」。
- 目前只規劃排版，卡片內容一律使用 `文字`，右下署名一律使用 `署名`，不要自行補寫正式文案。

## 卡片結構

- `.messages-grid` 內每位參與者對應一個 `<article class="message-card">`。
- 卡片內的 `<p>` 放留言，`<footer>` 放署名。
- 目前放置 6 張示意卡；實際人數確認後可直接增減完整的 `.message-card`，不需要修改 JavaScript。
- 卡片使用低透明暖紙、極淡邊界與內層亮線；不使用厚框、強陰影或高彩度底色。

## 可變人數與交錯規則

- 桌機使用 12 欄網格。奇數卡偏左、偶數卡偏右；每四張循環一次較窄的寬度與不同垂直落差。
- `nth-child` 規則會隨卡片數量循環，因此 1 張、奇數張或大量卡片都能自然結尾。
- 卡片高度由文字內容撐開，只設最低高度；較長留言不應裁切或固定高度。
- 700px 以下改為單欄，仍以不同寬度和左右靠齊保留交錯感，避免手機出現過窄雙欄。

## 修改檢查

- 新增或刪除任意張卡片後，沒有重疊、水平溢出或不自然的大空洞。
- 留言長短不同時，署名仍停在各卡片右下方。
- 手機版文字完整可讀，卡片不超出視窗。
- 章節順序、選單 active、左側章名與右緣滑標同步為六章。

## 更新此文件的時機

調整寄語章名、卡片數量、留言／署名結構、交錯規則、透明框樣式或手機排列時更新。
